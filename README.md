# BlenderBoss

Curso em português sobre a produção do T-6 Texan no Blender, da modelagem ao render. O progresso das 18 aulas fica salvo no navegador.

Baixe `BlenderBoss.html` e abra o arquivo no navegador. Na seção **Na viewport do Blender**, cada uma das sete aulas de modelagem tem duas capturas ampliáveis e uma cena editável, verificada no Blender 5.3. As fotografias históricas de referência precisam de conexão com a internet.

Para servir o site, use a pasta `dist` como raiz estática. Para reconstruir o HTML portátil a partir dela, execute `python tools/build_portable.py`.

Em **Aulas de nodes**, o laboratório traz duas trilhas com cinco aulas cada, quatro cenas editáveis e exercícios de conferência no Blender. Abra `#geometry-nodes` ou `#simulation-nodes` na página do curso.
